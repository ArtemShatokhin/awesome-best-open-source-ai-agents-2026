# Contributing

Thanks for contributing to `awesome-best-open-source-ai-agents-2026`.

## Submission Rules

- Every submission must have a public `github.com` repository URL.
- No proprietary SaaS-only tools.
- The repository must be relevant to AI agents, agent frameworks, browser agents, coding agents, agent infrastructure, or self-hosted assistant platforms.
- Include these fields in your pull request:
  - Tool name
  - GitHub URL
  - Short description
  - Stars
  - Primary language
  - License
  - Last commit or activity reference
  - Suggested category
  - Best-for use case
- If GitHub shows the license as `Other` or blank, call that out clearly.
- If a category has fewer than 5 strong repos, do not pad it with weak or unrelated entries. Document the gap honestly.

## Quality Standard

- Prefer established repositories with clear README documentation.
- Keep descriptions factual and specific.
- Do not submit listicles, blog posts, or closed hosted products.
- Use Markdown formatting consistent with the existing README.

## Pull Request Process

1. Fork the repo.
2. Add or update entries in `README.md`.
3. Keep the list GitHub-only.
4. Run a quick check that links work and the Markdown renders cleanly.
5. Open a pull request with a short rationale for the addition or change.

## Reporting Problems

Open an issue if:

- a repository is no longer public
- a link no longer points to GitHub
- a license entry is wrong
- a tool is actually proprietary or off-topic
- stars, language, or activity metadata needs updating
